# DongDa Website Deployment

This folder is a production-ready static-first website. Build and deploy `dist/client` as the web root.

## Build And Audit

```bash
npm run validate:content
npm run build:sites
npm run audit:launch
```

For Alibaba Cloud release, use the combined gate:

```bash
npm run preflight:aliyun
```

Only deploy after the gate passes.

## Recommended Hosting

Alibaba Cloud OSS + CDN is now the preferred deployment target.

1. Run `npm run preflight:aliyun`.
2. Upload the contents of `dist/client` to the OSS bucket root.
3. Set `index.html` as the default index document.
4. Put Alibaba Cloud CDN in front of the bucket and bind the final domain.
5. Configure HTTPS certificate on the CDN domain.
6. Confirm the upload includes `index.html`, `assets/`, `img/`, `manifest.json`, `robots.txt`, `sitemap.xml`, `content/`, and `ALIYUN_DEPLOYMENT.md`.
7. Purge CDN cache after every production upload.

Cloudflare Pages and WordPress staging scripts are preserved for fallback or historical comparison, but Alibaba Cloud is the current launch direction.

## Dynamic Content Seed

The first dynamic-upgrade layer is in `content/`:

- `content/products.json`
- `content/news.json`
- `content/company.json`
- `content/site-settings.json`
- `content/content-index.json`
- `content/runtime-config.json`

These files are copied into `dist/client/content` during build. They are not yet a live CMS, but they define the fields that should later move into WordPress Headless, Strapi, Directus or a custom Alibaba Cloud backend. `content/content-index.json` is generated by `npm run build:content` and can be used by future search, AI assistant grounding or sitemap automation. `content/runtime-config.json` is intentionally safe to publish and can be edited on OSS to point the static frontend at Alibaba Cloud Function Compute or API Gateway endpoints.

## Inquiry Form

The site works in static mode by default:

- Inquiry and quote forms generate a prepared email to `ynakobka@dongdaltd.com`.
- A local browser backup is stored in `localStorage` as `dongda_inquiries`.

For production CRM capture, update `content/runtime-config.json` after the API is ready:

```json
{
  "endpoints": {
    "inquiry": "https://your-api.example.com/inquiry",
    "aiService": "https://your-api.example.com/ai-service"
  }
}
```

The older script injection method is still supported if needed:

```html
<script>
window.DONGDA_INQUIRY_ENDPOINT = "https://your-worker-or-form-endpoint.example.com/inquiry";
</script>
```

The endpoint should accept JSON POST bodies.

## AI Customer Service

The site includes a floating AI customer-service assistant. It can classify common requests such as cement valve bags, cement FIBC ton bags, lead time, samples, and quote requests.

Static mode:

- The assistant prepares a sales email to `ynakobka@dongdaltd.com`.
- A local browser backup is stored in `localStorage` as `dongda_inquiries` and `dongda_ai_chat`.

Production automatic email mode:

```html
<script>
window.DONGDA_AI_ENDPOINT = "https://your-worker-or-crm-endpoint.example.com/ai-service";
</script>
```

The endpoint should accept JSON POST bodies and send the email server-side. A Worker template is included at `workers/ai-service-worker.js` for reuse or migration to Alibaba Cloud Function Compute.

Recommended Worker environment variables:

- `RESEND_API_KEY`: server-side email API key.
- `SALES_TO_EMAIL`: sales inbox, for example `ynakobka@dongdaltd.com`.
- `SALES_FROM_EMAIL`: verified sender, for example `DongDa <sales@yourdomain.com>`.
- `ALLOWED_ORIGIN`: production site origin, for example `https://china-litian.pages.dev`.
- `LEADS_WEBHOOK_URL`: optional CRM, sheet, or internal lead endpoint.
- `LEADS_WEBHOOK_TOKEN`: optional bearer token for the webhook.

Do not put SMTP passwords, mailbox passwords, or AI API keys in frontend JavaScript.

## Cache And Security

`_headers` sets:

- no-store for `index.html`
- immutable long cache for `/assets/*`
- common security headers suitable for a static B2B site

After visual or copy updates, change asset filenames or clear CDN cache if an asset is replaced with the same name.
